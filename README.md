# Books to Statements — Retail Accounting Cycle

A full manual build of a retail business's accounting cycle in Excel, from raw transactions to a complete financial picture. Built to demonstrate real understanding of double-entry accounting, not just formula usage.

## What this project covers

- **Chart of Accounts** — structured account list mapped to which financial statement each one flows into
- **Journal Entries** — 30 transactions covering cash and credit sales, credit purchases, accounts payable, accounts receivable, operating expenses, and asset purchases
- **Ledger** — built using Excel PivotTables, automatically aggregating debits and credits by account
- **Trial Balance** — PivotTable-driven, verifying debits equal credits before moving to statement prep
- **Income statement** - Using VLOOKUP To connect the sheets
- **Balance sheet** - A fully generated balancesheet

## Skills demonstrated

- Double-entry bookkeeping logic (debits, credits, account classification)
- Accounts Payable / Accounts Receivable handling for credit transactions
- Excel PivotTables for dynamic ledger and trial balance generation
- Chart of Accounts design linked to financial statement structure
